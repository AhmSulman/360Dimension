📋 Model Classes Initialized

ChatbotConfig

Configuration for the Mistral chatbot model - stores API keys, model settings, and parameters.

class ChatbotConfig(models.Model): name, mistral_api_key, mistral_model, max_tokens, temperature, etc.
Conversation

A chat conversation session - manages user chat sessions with unique IDs.

class Conversation(models.Model): user, session_id, title, config, messages (related), etc.
Message

An individual message in a conversation - stores user and assistant messages.

class Message(models.Model): conversation, role, content, tokens_used, created_at, etc.
Tool

Available tools/functions that the chatbot can use - enables function calling.

class Tool(models.Model): name, description, parameters (JSON), is_active, etc.
MistralChatService

Service class for interacting with Mistral models - handles AI generation and responses.

class MistralChatService: def generate_response(), def chat(), tokenizer & model properties, etc.
